Live Coach

Live Coach was a web panel for a Telegram bot used by a multilevel network to run its groups and channels: scheduled and recurring messages, hashtag-based points, and daily rankings.

I built it with Django and the Telegram Bot API. The bot registered groups and users, sent the messages, and tracked points; the web app was where editors managed content and access. That line of work later continued in Conectafam Plus.
